流操作

执行下面的命令，向指定的流追加一条消息条目。

XADD log:20260101 * IP 192.168.31.233 status 200

执行下面的命令，获取指定流的所有消息条目。

XRANGE log:20260101 - +

执行下面的命令，按逆序获取指定流的所有消息条目。

XREVRANGE log:20260101 + -

执行下面的命令，统计指定流中消息条目的总数。

XLEN log:20260101

执行下面的命令，删除流中指定 ID 的消息条目。

XDEL log:20260101 1790171494996-0

执行下面的命令，裁剪并只保留最新指定数量的消息条目。

XTRIM log:20260101 MAXLEN ~ 2
