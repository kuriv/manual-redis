性能测试

性能测试

执行下面的命令，读取慢查询日志。

SLOWLOG GET

执行下面的命令，统计慢查询日志队列记录总数。

SLOWLOG LEN

执行下面的命令，清空慢查询日志。

SLOWLOG RESET

还可以执行下面的命令，使用 Redis 的压力测试工具来进行性能测试。

redis-benchmark -t set,get -c 100 -n 1000000 -d 256 -r 100000 -q
