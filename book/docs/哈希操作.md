# 哈希操作

执行下面的命令，设置指定哈希的字段和值。

```
HSET user:233 name Tom age 20
```

执行下面的命令，获取指定哈希中单个字段的值。

```
HGET user:233 name
```

执行下面的命令，当指定哈希不存在时才设置字段和值。

```
HSETNX user:233 name Tom
```

执行下面的命令，获取指定哈希中多个字段的值。

```
HMGET user:233 name age
```

执行下面的命令，判断哈希中指定的字段名是否存在。

```
HEXISTS user:233 name
```

执行下面的命令，获取指定哈希中字段的总数。

```
HLEN user:233
```

执行下面的命令，获取指定哈希中所有的字段名。

```
HKEYS user:233
```

执行下面的命令，获取指定哈希中所有字段的值。

```
HVALS user:233
```

执行下面的命令，获取指定哈希中所有的字段名和值。

```
HGETALL user:233
```

执行下面的命令，删除哈希中指定的字段。

```
HDEL user:233 name age
```

执行下面的命令，按给定步长将哈希中指定字段的对应数值增加。

```
HINCRBY user:233 age 5
```
