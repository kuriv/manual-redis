# 列表操作

执行下面的命令，从列表头部插入一个或多个元素。

```
LPUSH list foo bar
```

执行下面的命令，从列表尾部插入一个或多个元素。

```
RPUSH list baz qux
```

执行下面的命令，移除并返回列表头部的第一个元素。

```
LPOP list
```

执行下面的命令，移除并返回列表尾部的最后一个元素。

```
RPOP list
```

执行下面的命令，从列表尾部弹出元素，随后插入到列表头部，并返回该元素。

```
RPOPLPUSH list1 list2
```

执行下面的命令，获取指定列表的元素个数。

```
LLEN list
```

执行下面的命令，获取指定列表对应下标位置的元素，其中， -1 表示最后一个元素。

```
LINDEX list -1
```

执行下面的命令，修改指定列表对应下标位置的元素。

```
LSET list 0 233
```

执行下面的命令，在列表中匹配到指定元素的前面插入新元素。

```
LINSERT list BEFORE 233 666
```

执行下面的命令，在列表中匹配到指定元素的后面插入新元素。

```
LINSERT list AFTER 233 666
```

执行下面的命令，删除列表中若干个指定值的元素。

```
LREM list 0 foo
```

执行下面的命令，获取列表指定下标区间内所有元素，其中， -1 表示最后一个元素。

```
LRANGE list 0 -1
```

执行下面的命令，裁剪并只保留指定下标区间内的元素。

```
LTRIM list 0 2
```
