# 地理空间操作

执行下面的命令，添加指定地点的经纬度坐标。

```
GEOADD China 104.04 30.4 Chengdu
```

执行下面的命令，获取指定地点的经纬度坐标。

```
GEOPOS China Chengdu
```

执行下面的命令，获取指定地点之间的距离。

```
GEODIST China Chengdu Beijing km
```

执行下面的命令，获取指定地点的哈希编码字符串。

```
GEOHASH China Chengdu
```

执行下面的命令，根据经纬度坐标或者已有地点，搜索指定范围内的地点。

```
GEOSEARCH China FROMMEMBER Chengdu BYRADIUS 500 km ASC WITHDIST
```
