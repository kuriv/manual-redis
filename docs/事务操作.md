# 事务操作

执行下面的命令，开启事务，后续输入的命令不会立刻执行，而是暂存入事务队列。

```
MULTI
```

执行下面的命令，一次性执行事务队列里的所有命令。

```
EXEC
```

执行下面的命令，放弃事务操作，同时清空队列。

```
DISCARD
```

执行下面的命令，监听指定的键，若该键被其他客户端修改，则放弃事务操作。

```
WATCH string
```

执行下面的命令，取消监听指定的键。

```
UNWATCH string
```

注意，若命令在暂存入事务队列期间报错，则整个事务全部不执行，若命令在执行期间报错，则仅仅错误的命令执行失败，其他正常命令继续执行，不会回滚。
