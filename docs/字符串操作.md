# 字符串操作

执行下面的命令，设置指定字符串的值。

```
SET string foo
```

执行下面的命令，获取指定字符串的值。

```
GET string
```

执行下面的命令，当指定的字符串不存在时才设置值。

```
SETNX string foo
```

执行下面的命令，批量设置多个字符串值，该命令具备原子性。

```
MSET string1 foo string2 bar string3 baz
```

执行下面的命令，批量获取多个字符串的值。

```
MGET string1 string2 string3
```

执行下面的命令，当所有指定的字符串全都不存在时，才批量设置多个键值。

```
MSETNX string1 foo string2 bar string3 baz
```

执行下面的命令，当指定的字符串不存在时才设置值，同时指定过期时间。

```
SET string foo NX EX 10
```

执行下面的命令，将给定的值追加到原字符串末尾。

```
APPEND string 233
```

执行下面的命令，获取指定字符串的长度。

```
STRLEN string
```

执行下面的命令，将指定的字符串对应数值自增。

```
INCR string
```

执行下面的命令，将指定的字符串对应数值自减。

```
DECR string
```

执行下面的命令，按给定步长将指定的字符串对应数值增加。

```
INCRBY string 5
```

执行下面的命令，按给定步长将指定的字符串对应数值减少。

```
DECRBY string 5
```

执行下面的命令，截取指定的字符串，其中， -1 表示最后一个字节。

```
GETRANGE string 0 -1
```

执行下面的命令，从指定偏移开始，覆盖写入字符串。

```
SETRANGE string 0 233
```
