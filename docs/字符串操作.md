# 字符串操作

执行下面的命令，设置指定的键值。

```
SET k1 v1
```

执行下面的命令，获取指定的键值。

```
GET k1
```

执行下面的命令，当指定的键不存在时才设置值。

```
SETNX k1 v1
```

执行下面的命令，批量设置多个键值，该命令具备原子性。

```
MSET k1 v1 k2 v2 k3 v3
```

执行下面的命令，批量获取多个键值。

```
MGET k1 k2 k3
```

执行下面的命令，当所有指定的键全都不存在时，才批量设置多个键值。

```
MSETNX k1 v1 k2 v2 k3 v3
```

执行下面的命令，将给定的值追加到原键值末尾。

```
APPEND k1 233
```

执行下面的命令，获取指定键值的长度。

```
STRLEN k1
```

执行下面的命令，将指定的键对应数值自增。

```
INCR k1
```

执行下面的命令，将指定的键对应数值自减。

```
DECR k1
```

执行下面的命令，按给定步长将指定的键对应数值增加。

```
INCRBY k1 5
```

执行下面的命令，按给定步长将指定的键对应数值减少。

```
DECRBY k1 5
```

执行下面的命令，截取指定的键值，其中， -1 表示最后一个字节。

```
GETRANGE k1 0 -1
```

执行下面的命令，从指定偏移开始，覆盖写入键值。

```
SETRANGE k1 0 233
```
