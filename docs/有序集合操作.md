# 有序集合操作

执行下面的命令，将一个或多个元素添加到指定有序集合中。

```
ZADD zset 60 foo 80 bar 40 baz
```

执行下面的命令，获取指定有序集合中的元素个数。

```
ZCARD zset
```

执行下面的命令，获取有序集合中分值在指定区间内的元素数量。

```
ZCOUNT zset 0 100
```

执行下面的命令，获取有序集合中指定元素的分值。

```
ZSCORE zset foo
```

执行下面的命令，删除有序集合中的指定元素。

```
ZREM zset foo
```

执行下面的命令，按升序获取有序集合中指定下标区间内的元素和分值。

```
ZRANGE zset 0 -1 WITHSCORES
```

执行下面的命令，按降序获取有序集合中指定下标区间内的元素和分值。

```
ZREVRANGE zset 0 -1 WITHSCORES
```

执行下面的命令，按分值升序获取分值在指定区间内的元素。

```
ZRANGEBYSCORE zset 0 100
```

执行下面的命令，按分值降序获取分值在指定区间内的元素。

```
ZREVRANGEBYSCORE zset 100 0
```

执行下面的命令，获取有序集合中指定成员的升序排名。

```
ZRANK zset foo
```

执行下面的命令，获取有序集合中指定成员的降序排名。

```
ZREVRANK zset foo
```

执行下面的命令，按给定步长将有序集合中指定成员的对应分值增加。

```
ZINCRBY zset 50 foo
```
