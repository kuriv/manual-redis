# 键操作

执行下面的命令，匹配当前数据库中所有的键。注意，该命令执行期间将阻塞主线程，无法处理其他任何请求，生产模式严禁使用。

```
KEYS *
```

执行下面的命令，匹配当前数据库中所有以指定字符开头的键。

```
KEYS str*
```

执行下面的命令，匹配当前数据库中所有以指定字符结尾的键。

```
KEYS *ing
```

执行下面的命令，匹配当前数据库中包含单个任意字符的键。

```
KEYS strin?
```

执行下面的命令，按通配符模式匹配包含任意一个字符的键。

```
KEYS strin[a-z]
```

执行下面的命令，使用游标迭代遍历数据中指定的键。

```
SCAN 0 MATCH str* COUNT 10
```

执行下面的命令，判断指定的键是否存在。

```
EXISTS string
```

执行下面的命令，查看指定键对应值的数据类型。

```
TYPE string
```

执行下面的命令，同步删除指定的键。

```
DEL string
```

执行下面的命令，异步删除指定的键。

```
UNLINK string
```

执行下面的命令，设置指定的键过期时间，以秒为单位。

```
EXPIRE string 10
```

执行下面的命令，查看指定的键剩余过期时间，其中， -1 表示键永久有效， -2 表示键已过期。

```
TTL string
```

执行下面的命令，移除指定键的过期时间并转为永久有效。

```
PERSIST string
```

执行下面的命令，重命名指定的键。

```
RENAME string str
```
