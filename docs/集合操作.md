# 集合操作

执行下面的命令，将一个或多个元素添加到指定集合中。

```
SADD set foo bar baz
```

执行下面的命令，获取指定集合中的所有元素。

```
SMEMBERS set
```

执行下面的命令，获取指定集合中的元素个数。

```
SCARD set
```

执行下面的命令，判断指定的元素是否存在于集合中。

```
SISMEMBER set foo
```

执行下面的命令，删除集合中的指定元素。

```
SREM set foo
```

执行下面的命令，从指定集合中随机删除并返回一个元素。

```
SPOP set
```

执行下面的命令，从指定集合中随机获取一个或多个元素。

```
SRANDMEMBER set 2
```

执行下面的命令，获取两个集合的并集元素。

```
SUNION set1 set2
```

执行下面的命令，获取两个集合的交集元素。

```
SINTER set1 set2
```

执行下面的命令，获取两个集合的差集元素。

```
SDIFF set1 set2
```
