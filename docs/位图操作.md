# 位图操作

执行下面的命令，设置位图指定偏移位的值，值只能是 0 或 1 。

```
SETBIT login:20260101 10 1
```

执行下面的命令，获取位图指定偏移位的值。

```
GETBIT login:20260101 10
```

执行下面的命令，统计指定位图中值为 1 的总数。

```
BITCOUNT login:20260101
```

执行下面的命令，查找位图中第一个指定值的位置。

```
BITPOS login:20260101 1
```

执行下面的命令，对多个位图执行按位运算，并将结果存储到指定的位图。

```
BITOP OR login:total login:20260101 login:20250101
```
